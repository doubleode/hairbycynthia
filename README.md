# Hair by Cynthia

Static website for Hair by Cynthia (Boise). Hosted free on Cloudflare Pages.

## Turning on online booking

Open `index.html` and paste Cynthia's Google Calendar booking link between the quotes here:

```html
<div id="site" data-booking-url="">
```

While it's empty, the site shows a "Book by text" card instead.

## Cloudflare Pages settings

- Framework preset: None
- Build command: (leave empty)
- Build output directory: `/`
